Purpose

The whole game. Fixed single screen — no camera, no scroll, no zoom, no minimap, no fog (FR-014, FR-015). Both bases are visible from the first frame, so the objective never has to be searched for or explained.

Ownership without colour (FR-018, WCAG 1.4.1)

Blue and red alone would fail 1.4.1, because the Kenney sprites bake team colour in. Every friendly unit therefore carries a persistent underglow ring (the blue halo above); enemies never do. The ring doubles as the selection affordance we needed anyway.

Build bar (FR-010, FR-011)

Exactly five entries — four unit entries plus one structure entry, the structure visually separated by the divider. Always visible, never nested. Unaffordable entries are greyed with the cost still shown (Tank, above) — never hidden, never a dialog (EDGE-004).

Ore nodes are the pressure valve

Nodes show remaining percentage and visibly deplete (FR-016). When a side's ore is gone, production halts and the match resolves with what is on the field (EDGE-006). No timer, no UI chrome, no explanation needed.

Under-attack indicator

The striped screen-edge band (JRN-003 STEP-002, FR-023) plus an audio cue. Losing without noticing is the worst possible outcome; on a fixed screen everything is visible, but attention is still finite.

States

Default · Units selected · Placement ghost (valid / invalid — EDGE-005) · Insufficient ore · Under attack · Ore exhausted.

Not a design system

This is a canvas game. The data-testid hooks above are the stable selectors for Playwright; there is no component library and no component-map.yml by decision.
