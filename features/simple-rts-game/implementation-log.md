## Deviations and open items carried out of M0

1. **`no-restricted-syntax` Map/Set clause is a PARTIAL guard.** `for...in` is banned
   outright. Detecting `for (const x of someMap)` needs type information a syntax
   selector does not have, so the config catches the `.keys()`/`.values()`/`.entries()`
   idiom and iteration of a Map/Set literal. **Bare iteration of a Map-typed variable
   slips through.** Residual risk is carried by the replay corpus (§IV), which fails the
   build when iteration order diverges across the matrix. Revisit if O-7 ever bites —
   type-aware linting via `projectService` is the escalation.
2. **Map and Set are not banned inside `src/sim/`**, only their unordered iteration. A*
   (T0xx) needs an open set, and a Map read through sorted keys is deterministic. The
   hazard is the iteration, not the container.
3. **CI matrix widened beyond plan.md** — 2 OS × 2 Node LTS lines (22 and 24) = 4 jobs,
   where the plan said "ubuntu + macos (Node LTS)". Node 24 entered LTS after the plan
   was written, and the local dev machine runs 24.4.1 while the plan pins 22.x. Rather
   than leave dev and CI on silently different engines, both are in the matrix — which
   is precisely the cross-engine hash agreement Constitution §IV exists to prove.
4. **Phaser pinned to 4.2.1, not the plan's 4.1.0.** Latest in the same minor line; the
   plan predates it. Phaser is presentation-only and cannot affect determinism.
5. **TypeScript stays on 5.9.3, exactly as planned.** TypeScript 7.0.2 is published, but
   `typescript-eslint@8.67` declares `typescript >=4.8.4 <6.1.0` — adopting TS 7 would
   mean giving up the boundary rules. The plan's "TypeScript 5.x" was the right call.
6. **`index.html` carries no entry script yet.** The Phaser entry arrives in M5. The page
   exists now so the `build` step is real from the first milestone; `vite build` produces
   `dist/index.html` and the toolchain is proven end to end.
7. **T006 CLOSED.** CI run 32523481346 — 4/4 jobs green (ubuntu + macOS x Node 22 + 24). Every runner logged `Lint correctly rejected a planted Math.random() in src/sim/__ci_canary__.ts`, so the boundary guard is proven on Linux as well as locally.
